# jcarlosrodicio/tap

Homebrew formulae for [norma](https://github.com/jcarlosrodicio/norma).

```sh
brew install jcarlosrodicio/tap/norma
```

Or `brew tap jcarlosrodicio/tap` and then `brew install norma`.

A new norma release reaches this tap through the `brew bump` workflow, which runs
daily and opens a pull request when GitHub has a newer release than the formula.
